## Этап 0. Утёкший ключ — сегодня, до всего остального

**Статус: подтверждено.** `raw.githubusercontent.com` отдаёт
`supabase/migrations/20260622000000_baseline.sql` без авторизации; в строках 275
и 279 — JWT с `"role":"service_role"`, `"ref":"gmvhphuabiyggfurfhmc"`, срок до
2036 года. В истории с коммита `8df37a3` (24.06.2026).

`service_role` обходит RLS целиком: все заявки, все токены клиентов, `auth`,
Storage мимо лимитов политики, любая RPC. Пока ключ жив, остальные пункты плана
смысла не имеют.

**Порядок — нарушение кладёт прод:**

1. *(подготовка, до ротации)* плейсхолдер `<SERVICE_ROLE_KEY>` в `baseline.sql`;
   `supabase/.temp/` в `.gitignore`; chat_id бухгалтеров плейсхолдером (M11.8);
   проверка на утечку в CI — `grep` по миграциям на `service_role`.
2. **Панель Supabase → Settings → API → ротация.** Делает владелец.
   Перед этим посмотреть, есть ли раздельные publishable/secret ключи: если да,
   ротация пройдёт без простоя.
3. **Сразу** — заголовки обоих Database Webhooks на новый ключ, иначе
   уведомления встают.
4. **Сразу** — новый anon-ключ в `app/js/config.js`, коммит, пуш.

Между шагом 2 и 4 фронт лежит — это минуты, и они неизбежны.

**Из истории git ключ не вычистить** (форки, кэши сканеров). Спасает только то,
что старый ключ станет мёртвым.

**Проверка готовности:** старый ключ отвергается REST; заявка на тестовой фирме
проходит путь «вопрос → ответ → уведомление» целиком.

## Этап 2. Убрать общий `save()` — архитектурный, главный

**Подтверждено:** `files` входит в `toRow()`, а `save()` делает upsert **всех**
заявок из состояния вкладки. «Последняя запись побеждает».

Один рефакторинг закрывает пять находок: **M1.1** (откат чужих статусов, риск
двойной оплаты), **M1.2** (статус из момента открытия формы), **M7.1** (файл из
ответа клиента затирается), **M4.8** (ложное «бухгалтер изменил» клиенту),
**M10.2** (затирание пишется в журнал как честная правка).

Суть: вместо upsert всего — точечные `update … where id = ? and status =
<ожидаемый>`. Не совпал статус — перечитать и сказать человеку, а не молча
перезаписать.

**Воспроизвести до починки:** две вкладки, в одной «Взять в работу», в другой
«Отметить оплаченным» — пять минут, снимает вопрос «а точно ли теряется».

День. Трогает `supabase.js`, `queue.js`, `main.js`.
