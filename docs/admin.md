# Руководство администратора

Администратор (владелец) заводит клиентов, закрепляет за ними бухгалтеров и выдаёт персональные ссылки. Вам доступно всё то же, что бухгалтеру, плюс вкладка **«Клиенты»** и вся очередь целиком.

> Telegram-бот проекта: **@paymentITNIMAX_bot**. В ссылках для перехода используется без `@`: `https://t.me/paymentITNIMAX_bot`.

---

## Вход
1. Откройте https://nikchyv.github.io/payments_new/app/
2. Войдите своим email и паролем.
3. Появятся вкладки **«Очередь платежей»**, **«Клиенты»**, **«Новая заявка»**, и в шапке — ваше имя с пометкой «владелец».

---

## Завести нового клиента

1. Вкладка **«Клиенты»**.
2. В строке добавления:
   - **Название компании** — например, `ООО «Ромашка»`.
   - **Бухгалтер** — выберите, кто будет вести этого клиента.
3. Нажмите **«Добавить»**.
4. В списке появится карточка клиента с кнопками **«Скопировать ссылку»** и **«🔄 Перевыпустить»**.

### Ссылка клиента
Кнопка «Скопировать ссылку» даёт **ссылку для сайта**:
```
https://nikchyv.github.io/payments_new/app/?t=КОД
```
где `КОД` (после `?t=`) — персональный токен клиента.

**Ссылка для Telegram-бота** формируется из того же кода (имя бота — без `@`):
```
https://t.me/paymentITNIMAX_bot?start=КОД
```
Просто подставьте `КОД` из ссылки сайта.

Пример: для кода `b4a6aedf5f1abe478f4091fa31bcdde6` ссылка бота —
`https://t.me/paymentITNIMAX_bot?start=b4a6aedf5f1abe478f4091fa31bcdde6`

> 🔒 Каждая ссылка персональна и открывает только платежи этого клиента. Передавайте её напрямую клиенту и просите не пересылать посторонним.

### Если у одного человека несколько фирм
Каждая фирма — **отдельный клиент со своей ссылкой**, объединять их не нужно.
Пусть человек нажмёт «Старт» по ссылке бота **каждой** фирмы: привязки
складываются, и уведомления пойдут по всем компаниям сразу. В сообщениях таким
людям бот подписывает название фирмы, чтобы не путались.

Заявки они заводят на сайте — бот при нескольких фирмах новую заявку не примет,
потому что не может определить, от какой компании она. Это сделано намеренно:
заявка, ушедшая не в ту фирму, всплывёт только на сверке.

Отвязать одну фирму от бота — **перевыпустить её ссылку** (см. ниже); остальные
привязки при этом сохраняются.

## Отозвать ссылку (перевыпуск)

Если ссылка клиента куда-то утекла — переслал не туда, попала в общий чат, ушла вместе с уволившимся сотрудником — её можно мгновенно обнулить.

1. Вкладка **«Клиенты»** → у нужного клиента нажмите **🔄 Перевыпустить**.
2. Подтвердите — появится предупреждение, что старая ссылка перестанет работать.
3. Скопируйте **новую** ссылку и отправьте клиенту.

**Что происходит:**
- старая ссылка умирает **сразу** — по ней нельзя ни посмотреть платежи, ни создать заявку;
- все платежи клиента остаются на месте, ничего не теряется;
- если клиент пользовался ботом, ему нужно **заново нажать «Старт»** по новой ссылке бота.

> Перевыпускать может только администратор. Бухгалтеру эта кнопка недоступна.

## Удалить клиента

Пробные и лишние записи можно убрать, чтобы не забивать список.

1. Вкладка **«Клиенты»** → в карточке нажмите **🗑 Удалить**.
2. Подтвердите. Ссылка клиента сразу перестаёт работать.

**Удаляются только клиенты без заявок.** В карточке рядом с бухгалтером написано
`заявок: N` — удалить получится того, у кого там `0`. Если заявки есть, система
откажет и скажет сколько их.

Так сделано намеренно: платежи ссылаются на клиента, и удаление клиента с
историей оставило бы заявки «ничьими» — из очереди бухгалтера они бы просто
исчезли. Если клиент с историей больше не нужен, лучше просто перевыпустить
ссылку и не отправлять её — история останется целой.

> Удалять может только администратор.

## Добавить нового бухгалтера

Отдельной кнопки в приложении пока нет — учётка заводится в один приём в панели Supabase:

1. **Supabase → Authentication → Users → Add user** — email и пароль сотрудника.
2. Скопируйте его **UID**.
3. **SQL Editor**, выполните (подставив UID и имя):
   ```sql
   insert into staff (id, name, is_admin) values ('UID', 'Имя сотрудника', false)
   on conflict (id) do nothing;
   ```
4. Передайте сотруднику email/пароль и [руководство бухгалтера](accountant.md).

После этого нового бухгалтера можно выбирать при заведении клиента.

### Уведомления новому сотруднику
Чтобы он получал сообщения бота:
1. Сотрудник пишет боту команду **/myid** и присылает вам число.
2. Этот `chat_id` нужно добавить **в двух местах** — в секрет `TELEGRAM_CHAT_ID` у Edge Functions и в список получателей в функции `send_daily_reminder`.

Подробности — в [RUNBOOK](RUNBOOK.md).

## Шаблоны сообщений для клиентов

Скопируйте, подставьте ссылки и отправьте.

### Шаблон 1 — короткий (сайт)
```
Здравствуйте! Подключаем вас к сервису заявок на оплату.
Ваша персональная ссылка: <ССЫЛКА_САЙТА>

По ней можно оставить заявку на платёж и следить за его статусом.
Ссылка личная — пожалуйста, не передавайте её другим.
```

### Шаблон 2 — с Telegram-ботом
```
Здравствуйте! Оставлять заявки на оплату можно двумя способами:

🌐 Сайт: <ССЫЛКА_САЙТА>
🤖 Telegram-бот: <ССЫЛКА_БОТА>
   (перейдите и нажмите «Старт» — привязка одноразовая)

Что умеет:
• оставить заявку на оплату (можно приложить фото счёта);
• видеть статус: принята → в работе → оплачено;
• бот сам пришлёт, когда платёж оплачен.

Ссылки персональные — не передавайте посторонним.
```

### Шаблон 3 — инструкция «как оставить заявку»
```
Чтобы оставить заявку на оплату:
1. Откройте ссылку и вкладку «Новая заявка» (или в боте — /new).
2. Укажите получателя, сумму, дату платежа.
3. По желанию приложите фото или PDF счёта.
4. Отправьте — мы увидим заявку сразу.

Пара полезных моментов:
• Ошиблись? Пока мы не взяли заявку в работу, её можно поправить —
  кнопка «Редактировать» во вкладке «Мои платежи».
• Галочка «Нужен платёжный документ» снята по умолчанию — поставьте,
  если нужно подтверждение оплаты.
• Мы работаем пн–пт до 17:00. Если отправите заявку «на сегодня» после
  17:00 или в выходной, срок автоматически переедет на ближайший рабочий
  день. Планировать наперёд можно в любое время.

Статус платежа — во вкладке «Мои платежи» (в боте — /payments).
```

### Шаблон 4 — новая ссылка после перевыпуска
```
Здравствуйте! Мы обновили вашу персональную ссылку — прежняя больше
не работает.

🌐 Новая ссылка: <ССЫЛКА_САЙТА>
🤖 Бот: <ССЫЛКА_БОТА> (нужно снова нажать «Старт»)

Все ваши платежи на месте, ничего не потерялось.
```
